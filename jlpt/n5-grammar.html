Como usar esta página

Cada linha é um ponto de gramática do N5. Toque nela para ver o que expressa, como se forma e frases de exemplo com furigana, romaji e áudio. Cada ponto abre separadamente.

São cartões curtos e próprios deste projeto, para consulta e revisão. Quando o ponto é explicado em uma das lições do site, aparece a etiqueta Lição N e, dentro do cartão, o link Ver na lição. As lições seguem o Minna no Nihongo; aqui o foco é o que costuma cair no JLPT.

Para as formas dos verbos (ます, て, ない, た...), use a página de verbos.
